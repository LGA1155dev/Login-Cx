## 📖 Sobre o projeto

O **Login-Cx** é um projeto de interface web que simula uma página de login e cadastro de uma agência fictícia.

O projeto foi desenvolvido exclusivamente para fins educacionais, com o objetivo de explorar a construção de interfaces de autenticação, organização de formulários, estilização de elementos e criação de diferentes páginas de interação com o usuário.

A proposta é reproduzir visualmente elementos comuns em sistemas de login, como campos de entrada, botões, formulários de cadastro e telas de retorno, utilizando tecnologias frontend.

O projeto não representa um serviço real, não está vinculado a uma empresa ou agência legítima e não possui finalidade de coletar credenciais de usuários.

## 💡 Proposta do projeto

Interfaces de autenticação estão presentes em praticamente todos os serviços digitais, desde redes sociais até plataformas de comércio eletrônico, sistemas corporativos e aplicações web.

Construir uma interface desse tipo permite estudar elementos que fazem parte de experiências digitais comuns, como:

- Campos de entrada de dados.
- Formulários.
- Botões de ação.
- Organização visual.
- Hierarquia de informações.
- Feedback visual.
- Navegação entre telas.

O Login-Cx foi criado como um exercício prático para explorar esses componentes e entender como uma interface de login é estruturada visualmente.

## ✨ Funcionalidades e páginas

O repositório possui diferentes páginas e arquivos de estilização, incluindo:

## 🚀 Como executar localmente

Você pode executar o projeto localmente para visualizar a interface ou estudar seu código.

### 1️⃣ Clone o repositório

```bash
git clone https://github.com/LGA1155dev/Login-Cx.git
```

### 2️⃣ Acesse a pasta

```bash
cd Login-Cx
```

### 3️⃣ Abra o projeto

Abra o arquivo `index.html` diretamente no navegador.

## ⚠️ Aviso de segurança e finalidade educacional

Este projeto é uma interface de login fictícia criada exclusivamente para estudos de desenvolvimento frontend.

- 🚫 Não pertence a uma empresa, agência ou serviço real.
- 🚫 Não deve ser utilizado para se passar por plataformas ou organizações legítimas.
- 🚫 Não possui finalidade de capturar, armazenar ou transmitir credenciais reais.
- 🚫 Não representa um sistema de autenticação funcional ou seguro.

A interface visual de um login, por si só, não implementa autenticação. Um sistema real precisaria de backend, validação, armazenamento seguro, gerenciamento de sessões, proteção contra ataques e outras medidas de segurança.

O projeto deve ser utilizado somente em contextos educacionais e de desenvolvimento.
